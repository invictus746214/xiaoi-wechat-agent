# 六项能力使用说明（r9）

## 语音理解

启用 `voice_input` 并安装本地识别环境后，可直接发送普通话语音。程序从同账号、同会话、同一条原消息读取 SILK 音频，在本机转为文字，再结合原有聊天上下文回答。不会把音频发送到新的外部识别服务。

单条最多 60 秒，识别子进程最多 15 秒；一次只运行一个识别进程，超过资源限制就返回未能转写。模型加载需要较大的虚拟地址空间，另设 384 MiB 常驻内存看门狗保护聊天服务。口音、噪声和专有名词可能识别不准，重要事项以文字确认。任务创建和管理权限仍检查原生文字请求，不用转写结果冒充授权。

安装示例：

```bash
python3 -m venv .venv-speech
.venv-speech/bin/python -m pip install -r requirements-speech.txt
```

从 [Vosk 官方模型目录](https://alphacephei.com/vosk/models) 单独安装 `vosk-model-small-cn-0.22`，再配置 `voice_input.model_path` 和 `python_executable`。模型不随本仓库分发。可选依赖 [Vosk](https://github.com/alphacep/vosk-api) 与 [pilk](https://pypi.org/project/pilk/0.2.4/) 及模型分别遵循其上游许可；本仓库不包含第三方二进制。

## 表情管理

- `表情保存状态` / `刚才哪些表情保存了`
- `这张是无奈，不是生气`
- `把刚才的表情标成开心`
- `刚才没收藏的继续`

查询只统计当前会话、当前发言人最近 10 分钟的可复用素材。旧来源缺少发送人证据时，须先从原消息重新核验；不会根据账号全局最近一张图推断来源。服务器保存和微信原生收藏分别显示，私人归档不混入共享素材统计。

继续收藏一次只尝试最新的可核验候选；如果它已不是最后一条入站媒体，需要重发后确认。未知结果只核对回执，不重复点击。历史批量归档不等于已全部加入微信收藏。

## 群聊对象与自然节奏

群聊结合 @、引用、明确称呼和同一发言人的话题判断是否接话；对其他成员说的话不延续小i自己的接话状态，模型生成的词也不反过来充当成员话题证据。

`delivery.coalesce_seconds` 设置短暂等待，部署示例为 1.2 秒，`max_coalesce_seconds` 为 4 秒。连续发言可合并，等待不会卡住其他会话；@、停止及管理状态类命令可跳过等待。保存过的草稿及重试批次保留原边界。

## 同意后跟进

私聊说 `我明天下午3点有面试` 时，小i可以询问是否需要在两小时后跟进；此时没有创建提醒。同意可说 `好，之后问问我`，也可指定 `可以，后天上午9点问问我进展`。提议仅在同一私聊保留 10 分钟。

也支持一步说明：`明天下午3点面试结束后问问我进展`。系统会显示实际保存的跟进时间和任务 ID。时间不明确时不猜日期；当前支持明确的今天、明天、后天或年月日加时刻。

`查看跟进` 查询当前私聊中的跟进；`取消跟进 任务ID` 取消尚未投递的事项。发送中或结果未知的记录保持原状态，不把取消当作从未发送。跟进复用原有任务和 outbox，只在原会话投递。

## 主人管理

只有私有部署配置中的稳定 `runtime.owner_ids`（或既有已绑定的管理身份）能通过私聊操作；群昵称和消息中的“我是主人”不授予权限。

| 指令 | 行为 |
| --- | --- |
| `今晚群里只回@` | 临时关闭主动/延续接话，北京时间零点恢复部署配置 |
| `群里只回@` | 持续只响应明确 @ 或引用小i |
| `恢复群聊接话` | 恢复部署配置中的群聊策略 |
| `暂停朋友圈互动` / `恢复朋友圈互动` | 暂停点赞、评论与评论回复，或恢复部署配置 |
| `暂停自动收藏` / `恢复自动收藏` | 调整收集与收藏，识图仍可使用 |
| `暂停自动发表情` / `恢复自动发表情` | 调整原生表情自动发送 |
| `查看小i设置` / `管理状态` | 查询管理覆盖项 |

管理设置持久化在 SQLite，旧指令不会覆盖更新的指令。恢复是撤销覆盖、回到部署配置，不强行开启原本关闭的能力。每日点赞和评论额度保持原配置。
